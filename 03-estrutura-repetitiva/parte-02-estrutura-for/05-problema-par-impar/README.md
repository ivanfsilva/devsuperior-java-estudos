# Problema "par_impar"

Leia um valor inteiro N. Este valor será a quantidade de números inteiros que serão lidos em seguida. Para cada valor
lido, mostre uma mensagem dizendo se este valor lido é PAR ou IMPAR, e também se é POSITIVO ou NEGATIVO. No caso do
valor ser igual a zero (0), seu programa deverá imprimir apenas NULO.

## Exemplo de entrada e saída

### Entrada

| Entrada                               | Exemplo 1 |
|:--------------------------------------|:----------|
| **Quantos numeros voce vai digitar?** | 4         |
| **Digite um numero:**                 | -5        |
| **Digite um numero:**                 | 0         |
| **Digite um numero:**                 | 3         |
| **Digite um numero:**                 | -4        |

### Saída

| Saída         | Exemplo 1                                                      |
|:--------------|:---------------------------------------------------------------|
| **Resultado** | IMPAR NEGATIVO <br> NULO <br> IMPAR POSITIVO <br> PAR NEGATIVO |
