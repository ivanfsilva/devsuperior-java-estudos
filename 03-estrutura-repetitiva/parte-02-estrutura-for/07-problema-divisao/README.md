# Problema "divisao"

Escreva um algoritmo que leia um número inteiro N, e depois repita N vezes: ler dois números e imprimir o resultado da
divisão do primeiro pelo segundo. Caso não for possível, mostre a mensagem "DIVISAO IMPOSSIVEL".

## Exemplo de entrada e saída

### Entrada

| Entrada                             | Exemplo 1 |
|:------------------------------------|:----------|
| **Quantos casos voce vai digitar?** | 3         |
| **Entre com o numerador:**          | 3         |
| **Entre com o denominador:**        | -2        |
| **Entre com o numerador:**          | -8        |
| **Entre com o denominador:**        | 0         |
| **Entre com o numerador:**          | 0         |
| **Entre com o denominador:**        | 8         |

### Saída

| Saída         | Exemplo 1                                                   |
|:--------------|:------------------------------------------------------------|
| **Resultado** | DIVISAO = -1.50 <br> DIVISAO IMPOSSIVEL <br> DIVISAO = 0.00 |
