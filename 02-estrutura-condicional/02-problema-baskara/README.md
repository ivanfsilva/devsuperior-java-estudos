# Problema "baskara"

Fazer um programa para ler os três coeficientes de uma equação do segundo grau. Usando a fórmula de Baskara, calcular e
mostrar os valores das raízes x1 e x2 da equação com quatro casas decimais, conforme exemplo. Se a equação não possuir
raízes reais, mostrar uma mensagem.

## Exemplo de entrada e saída

### Entrada

| Entrada            | Exemplo 1 | Exemplo 2 | Exemplo 3 |
|:-------------------|:----------|:----------|:----------|
| **Coeficiente a:** | 1         | 2         | 1         |
| **Coeficiente b:** | 0         | -4.5      | 3         |
| **Coeficiente c:** | -9        | 1.7       | 4         |

### Saída

| Saída    | Exemplo 1 | Exemplo 2 | Exemplo 3                            |
|:---------|:----------|:----------|:-------------------------------------|
| **X1 =** | 3.0000    | 1.7697    | Esta equação não possui raízes reais |
| **X2 =** | -3.0000   | 0.4803    |                                      |
