# Problema "dardo"

No arremesso de dardo, o atleta tem três chances para lançar o dardo à maior distância que conseguir. Você deve criar um
programa para, dadas as medidas das três tentativas de lançamento, informar qual foi a maior.

## Exemplo de entrada e saída

### Entrada

| Entrada                        | Exemplo 1 | Exemplo 2 |
|:-------------------------------|:----------|:----------|
| **Digite as tres distancias:** | 83.21     | 83.21     |
|                                | 79.53     | 87.20     |
|                                | 89.15     | 83.21     |

### Saída

| Saída                 | Exemplo 1 | Exemplo 2 |
|:----------------------|:----------|:----------|
| **MAIOR DISTANCIA =** | 89.15     | 87.20     |
