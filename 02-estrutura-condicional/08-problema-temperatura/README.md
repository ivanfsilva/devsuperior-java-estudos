# Problema "temperatura"

Deseja-se converter uma medida de temperatura da escala Celsius para Fahrenheit ou vice-versa. Para isso, você deve
construir um programa que leia a letra "C" ou "F" indicando em qual escala vai ser informada uma temperatura. Em seguida
o programa deve mostrar a temperatura na outra escala com duas casas decimais. A seguir é dada a fórmula para converter
de Fahrenheit para Celsius: $C = \frac{5}{9} \times (F - 32)$ (você deve deduzir a fórmula de Celsius para Fahrenheit:
$F = \frac{9}{5} \times C + 32$).

## Exemplo de entrada e saída

### Entrada

| Entrada                                                  | Exemplo 1 | Exemplo 2 |
|:---------------------------------------------------------|:----------|:----------|
| **Voce vai digitar a temperatura em qual escala (C/F)?** | F         | C         |
| **Digite a temperatura em Fahrenheit:**                  | 75.00     |           |
| **Digite a temperatura em Celsius:**                     |           | 28.15     |

### Saída

| Saída                                      | Exemplo 1 | Exemplo 2 |
|:-------------------------------------------|:----------|:----------|
| **Temperatura equivalente em Celsius:**    | 23.89     |           |
| **Temperatura equivalente em Fahrenheit:** |           | 82.67     |
