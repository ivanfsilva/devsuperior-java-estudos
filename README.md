# 📚 Estudos de Java & Orientação a Objetos (DevSuperior)

Este repositório contém as soluções dos exercícios, desafios e projetos práticos desenvolvidos durante os treinamentos de Java da plataforma **DevSuperior**, ministrados pelo Prof. Dr. Nélio Alves.

O objetivo deste espaço é registrar minha evolução na linguagem Java, aplicando conceitos que vão desde a lógica de programação até o paradigma de Orientação a Objetos e estruturas de dados.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java (JDK 17+)
- **IDE:** IntelliJ IDEA
- **Controle de Versão:** Git & GitHub

---

## 📂 Estrutura de Conteúdos

Os exercícios estão consolidados e organizados em subpastas numeradas por tópicos/capítulos. Cada desafio contém seu próprio enunciado e solução.

|  Cap.  | Módulo / Tópico                   | Conteúdo Principal                                        |     Status      |
| :----: | :-------------------------------- | :-------------------------------------------------------- | :-------------: |
| **01** | `01-estrutura-sequencial`         | Entrada/saída de dados, operadores, funções matemáticas   |  ✅ Concluído   |
| **02** | `02-estrutura-condicional`        | Estruturas `if-else`, `switch-case`, operadores lógicos   | ⏳ Em andamento |
| **03** | `03-estruturas-repetitivas`       | Laços `while`, `for`, `do-while`                          |  📅 Planejado   |
| **04** | `04-orientacao-a-objetos`         | Classes, atributos, métodos, membros estáticos            |  📅 Planejado   |
| **05** | `05-construtores-encapsulamento`  | Sobrecarga, encapsulamento, `this`, getters/setters       |  📅 Planejado   |
| **06** | `06-comportamento-memoria-arrays` | Tipos referência vs. valor, GC, vetores e listas (`List`) |  📅 Planejado   |
| **07** | `07-heranca-polimorfismo`         | Sobreposição, `super`, polimorfismo, classes abstratas    |  📅 Planejado   |
| **08** | `08-tratamento-excecoes`          | Estrutura `try-catch`, exceções personalizadas            |  📅 Planejado   |
